# Capsule

Особистий цифровий гардероб і ІІ-стиліст: фото речей, фільтри, а далі — образи, аналіз натхнення і розумні покупки.

## Запуск локально

```bash
npm install --prefer-offline
npm run dev
```

## Деплой

```bash
npm run deploy
```

Збирає застосунок і викладає його на GitHub Pages: https://innademidova.github.io/capsule/

## База даних

Supabase (проєкт «Style»). Повна схема — `supabase/schema.sql`. Пароль для входу — у `.env.local` (не в git).
